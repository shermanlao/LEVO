# LEVO

Lighting catalog site (Next.js) plus Express API and SQLite.

See [markdown_index.md](markdown_index.md) for guides.

## Run

```bash
npm run dev
```

- Site: http://localhost:3000
- API: http://127.0.0.1:3333
- Database: `backend-server/database.sqlite` (created locally; not committed)
- Admin: http://localhost:3000/admin

Clone this repo, run `npm install` at the root plus `frontend` and `backend-server`, then `npm run dev`. Local `node_modules`, `.next`, and SQLite files are gitignored.
